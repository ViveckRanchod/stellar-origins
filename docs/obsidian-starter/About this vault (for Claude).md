This Obsidian vault holds the notes for the **Stellar Origins** workshop website (always spelled "Stellar").
The website's code lives on GitHub at ViveckRanchod/stellar-origins, and changes are made there through
Claude Code cloud sessions, not in this folder.

When I work with you in this vault:
- Help me turn feedback and ideas into clear items in "Change requests.md": page, what it says now, what it should say.
- When I say a change is live, move it to Done and add a row to "Change log.md" with today's date.
- "Site content template.md" lists every piece of wording on the site; keep it in step with changes I tell you about.
- "Collecting data.md" explains how to export answers; if I give you a CSV export, summarise it plainly.
- Keep notes short and plain. Don't invent content; ask me when something is unclear.
